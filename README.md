# 🚀 apigw-mock-helper

一个专为本地/局域网内进行 API 路由分发、TLS/JA3 握手特征模拟以及 JSON 数据中转测试而设计的轻量级 **FastAPI 代理与协议测试网关**。

---

## ✨ 核心特性

1.  **动态 API 路由分发**：内置多源检索中转机制，支持将单次网络请求分发合并，并在毫秒级内合并返回纯净的标准化 JSON 格式数据。
2.  **高抗阻协议混淆**：全线基于 `curl_cffi` 强力网络库，完美模拟主流浏览器的 TLS JA3/JA4 握手特征和 HTTP/2 标头帧顺序，用于在协议开发阶段绕过严苛的反网络扫描防火墙。
3.  **多节点资源指引**：支持下发多达 18+ 外部测试节点的分布式路由规则，配合客户端变量实现无痛的客户端直连路由切换测试。
4.  **安全防验证托管**：在协议对接中，将需要进行人机安全校验的敏感正文请求安全分发托管给客户端浏览器内核，避免服务端中转时被卡死。
5.  **本地轻量数据注册表**：内置轻量持久化 SQLite 数据库，无缝支持客户端用户的注册、鉴权、数据节点增删改查。

## 🛠️ 快速启动指南

### 1. 💻 Windows 平台一键双击运行

1.  进入 `legado_server/` 文件夹。
2.  双击运行 **`run.bat`**。
3.  脚本会自动检测并使用 `uv` 创建专属虚拟环境、补齐依赖并启动服务。

### 2. 🐧 Linux / 1Panel 平台部署

#### 路线 A：使用 1Panel 内置的“Python 运行环境”
1.  将 `legado_server` 文件夹上传到服务器的任意目录（如 `/opt/legado_server`）。
2.  在 1Panel 面板的“环境” -> “Python”中，**创建 Python 环境**，路径选择您的项目目录，版本选择 `3.12`。
3.  在 1Panel 的“系统” -> “守护进程”中，添加一个进程：
    *   运行目录：`/opt/legado_server`
    *   启动命令：`/opt/legado_server/.venv/bin/python main.py`

#### 路线 B：使用 Docker 容器化一键构建
1.  将 `legado_server` 文件夹上传到服务器。
2.  在 1Panel 中进入“容器” -> “镜像” -> “构建镜像”，目录指向包含 `Dockerfile` 的文件夹。
3.  镜像构建完毕后，创建容器并映射主机的 **`8000`** 端口即可！
