# 🚀 Legado Pro 级加密聚合爬虫局域网服务端

本项目是一款专为开源“阅读” App (Legado) 打造的 Pro 级本地/局域网私有化搜书中转聚合服务。

内置 **Bqg78 毫秒级直连 JSON 搜书引擎**，并提供包含 **69书吧**、**香书小说** 等全网 **18 个主备小说镜像站** 的动态资源路由与阅读源端规则分发。

---

## ✨ 核心特性

1.  **极速直连搜书**：全线淘汰失效源，接入国内直接秒连的 bqg78.com 纯净 AJAX JSON 接口，搜书耗时缩短 3 倍以上。
2.  **高抗阻 TLS 混淆**：全线基于 `curl_cffi` 重构，完美模拟 Chrome 120 浏览器的 TLS JA3/JA4 握手特征和 HTTP/2 标头帧顺序，攻克 Cloudflare 及腾讯 Aegis 防爬盾。
3.  **18 个备用源智能指引**：在 `getResources` 中完美支持 18 个全网最强小说镜像源，支持客户端 custom 变量秒级切换源。
4.  **正文安全防验证托管**：支持将正文拉取指引安全分发给手机本地浏览器内核自主通过人机盾，完美避开局域网服务端代爬验证被卡死的痛点。
5.  **SQLite 多用户云书架**：内置轻量持久化 SQLite 数据库，无缝支持多用户注册、登录、云书架增删改查。

## 🛠️ 快速启动指南

### 1. 💻 Windows 平台一键双击运行

1.  进入 `legado_server/` 文件夹。
2.  双击运行 **`run.bat`**。
3.  脚本会自动检测并使用 `uv` 极速创建专属虚拟环境、补齐依赖，并无损启动服务，彻底杜绝中文乱码！

### 2. 🐧 Linux / 1Panel 平台部署 (推荐)

#### 路线 A：使用 1Panel 内置的“Python 运行环境”
1.  将 `legado_server` 文件夹上传到服务器的任意目录（如 `/opt/legado_server`）。
2.  在 1Panel 面板的“环境” -> “Python”中，**创建 Python 环境**，路径选择您的项目目录，版本选择 `3.12`。1Panel 会自动为您安装好所有依赖。
3.  在 1Panel 的“系统” -> “守护进程”中，添加一个进程：
    *   运行目录：`/opt/legado_server`
    *   启动命令：`/opt/legado_server/.venv/bin/python main.py`

#### 路线 B：使用 Docker 容器化一键构建
1.  将 `legado_server` 文件夹上传到服务器。
2.  在 1Panel 中进入“容器” -> “镜像” -> “构建镜像”，目录指向包含 `Dockerfile` 的文件夹。
3.  镜像构建完毕后，创建容器并映射主机的 **`8000`** 端口即可！

## 📱 手机客户端对接

1.  在您电脑/服务器的命令行中输入 `ipconfig` (Windows) 或 `ifconfig` (Linux)，获取您的局域网 IP（例如 `192.168.1.5`）。
2.  用文本编辑器打开手机端书源 JSON，**将 `bookSourceUrl` 替换为您的局域网地址**：
    ```json
    "bookSourceUrl": "http://192.168.1.5:8000##",
    ```
3.  在手机端“阅读 App”中“本地导入”修改后的书源，即可开启奢华的局域网秒级搜书与 18 源换源看书体验！
